# Changelog

## 0.3.0

- Added the editor shell and portrait and landscape layouts, 40 bundled fonts, and JSON text and caption libraries.
- Added the animation engine, caption tracks and file workflows, and shared PNG-sequence export.
- Added version 2 project migration, Layers, keyboard shortcuts, and clip tools.

## 0.2.0

- Added 12 text style presets with swatches and expanded entrance and exit animations.
- Added a button to preview the selected clip's animation in the editor. Preview and export share the motion settings.

## M9

- Added autosave, crash recovery, missing-media relinking, project settings, Save As, and resizable editor panels.
- Added the layered demo generator, release checks, and the Windows NSIS build.

## M8

- Added verified 4K60 export, encoding presets, hardware encoder probing, software fallback, and output size and free-space checks.

## M7

- Added FFmpeg video and audio export with shared Canvas text, progress, cancellation, range selection, and ffprobe verification.

## M6

- Added text clips, on-canvas editing, bundled fonts, style presets, and a shared Canvas text rasterizer.

## M5

- Added multi-track Web Audio mixing, track and clip controls, speed, detach audio, waveform caching, and a master meter.

## M4

- Added the layered canvas, playback clock, scrubbing, preview quality, proxy playback, and on-canvas transform handles.

## M3

- Added multi-track editing with asset drops, track management, group movement, trim, split, ripple deletion, snapping, markers, and timeline navigation.

## M2

- Added a filterable media bin, ffprobe import, thumbnails, background preview proxies, and undo/redo.

## 0.1.0 · M1

- Added the desktop shell, searchable recent projects, project setup, and app preferences.
- Added validated portable project files, safe saves, and project management from Home.
- Added project persistence tests and an Electron create/save/reopen smoke test.
